I managed to fix the object loading! A while ago, in order to account for the increase in level size, I added some code that spaced the spawn location of the objects. This code however, didn't shift the spawn boxes. Additionally, this change applied to every object being loaded, including an object that was previously loaded and unloaded. This caused the objects to shift another 2 metatiles every time they were reloaded (see video). 
Unfortunately, due to the long break between the last time I worked on this project and now, I forgot about that code.
So, when I came back to the problem, I added a function that shifted the spawnboxes instead of the spawn location. With the way spawning works, this also shifts the object's spawn location. Also, this newer function only runs once, just after the object table has been loaded. This means that, unlike before, objects that get re-entered into the table do not get shifted again. Additionally, unlike the last version, this new function doesn't even touch an object that is not in the table, such as the projectiles. 
However, as mentioned, I forgot about the old change, and spent a while, frustrated, trying to figure out why the new function wasn't working. Eventually I rediscovered that old code and removed it.
